### dsh
- 定义：DeepSeek Harness 的命令行入口与发行名，通过 `npx @deepseek-ai/dsh` 或 `pnpm dsh` 调用，支持 `web`、`--profile`、`--dump-config`、`--patch` 等子命令。
- 别名：DeepSeek Harness、DSH

### Service
- 定义：Cordis 插件的基本单元，可以是带可选 inject 与 apply(ctx) 的函数，也可以是继承 Cordis Service 的类；通过 ctx.<key> 暴露给其他插件发现。
- 别名：服务

### ctx.key
- 定义：插件间共享能力的命名空间键（如 ctx.tools、ctx.llm、ctx.sessions、ctx.fs、ctx.subprocess、ctx.e2b），插件通过注入该 key 访问能力而非直接 import 具体实现。
- 别名：上下文键、ctx 键

### capability seam
- 定义：将某项能力拆为 Service Definition（契约）、Service Provider（具体实现）与 Consumer（使用者）三层，使同一消费者可替换不同后端（如 fs-local / fs-e2b、subprocess-local / subprocess-e2b）。
- 别名：能力边界、能力分离

### preset
- 定义：通过 per-session 的 cordis.yml 文件组装 agent 的插件组合，是 dsh 启动时加载的插件配置来源之一。
- 别名：预设

### bundle
- 定义：可安装的 dsh --profile 补丁层，作为一组插件/配置的 patch 集合供 dsh 启动时叠加。
- 别名：补丁层、bundle 层

### extension
- 定义：agent 运行时的自修改能力：允许在运行时检查/挂载/卸载插件与服务，实现模型驱动的插件编排。
- 别名：扩展

### session data plane
- 定义：会话持久化数据面，提供 JSONL/SQLite 后端、projection 抽象、基于日志的标题生成与会话报告能力。
- 别名：会话数据平面

### Typert RPC
- 定义：api 包的远程 BFF 组装与基于 Typert 的类型安全 RPC 网关，用于 host/client 之间的类型契约通信。
- 别名：RPC 网关

### ACM / ACP
- 定义：Automation-only Agent Client Protocol server，提供自动化场景下的 agent 客户端协议服务端。
- 别名：Agent Client Protocol、ACP server
