模块由两个相互依赖的 Hatchling 包组成：
- `python/sdk`（`deepseek-harness-sdk`）：对外暴露 `DeepSeekHarness`/`Session`/`RunResult` 等高阶 API（`api.py`），内部通过 `client.HarnessClient` 以 JSON-RPC 2.0 协议与子进程通信；`models.py` 定义共享的 `Notification`、`IncomingRequest`、`InitializeResponse` 等 Pydantic/dataclass 类型；`errors.py` 集中异常类型。
- `python/sdk-runtime`（`deepseek-harness-runtime-bin`）：纯数据包，不包含业务逻辑，仅通过 `__init__.py` 中的 `resolve_bundled_launch_args()`、`bundled_runtime_path()`、`bundled_default_config_path()` 在运行时定位平台特定的单文件 Node 可执行产物（`dsh-jsonrpc-agent-pkg-<platform>-<arch>`）或开发期 node 闭包，并把默认 `runtime/cordis.yml` 路径注入到子进程环境变量 `DSH_CORDIS_CONFIG`。
依赖方向单向：SDK → runtime-bin 解析器 → 外部 Node 可执行；SDK 通过 `subprocess.Popen` 管理生命周期，使用 `threading.Lock` + `queue.Queue` 实现请求-响应等待、通知订阅与 stderr 采集，并以 `shutdown` 方法优雅关闭子进程。构建时通过 `uv.sources` 将 runtime-bin 以 editable 方式链接，使 SDK 测试可直接复用源码目录下的构建产物。
