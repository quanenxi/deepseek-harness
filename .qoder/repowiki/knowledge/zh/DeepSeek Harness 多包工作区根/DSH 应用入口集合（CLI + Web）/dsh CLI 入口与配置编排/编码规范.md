- 每个 CLI 模式封装为独立模块（profile-boot、plugin、dump-config），由 bin.ts 通过 `await import` 按需加载，避免无关代码进入二进制。
- 参数解析返回带判别字段 `mode` 的联合类型 `DshInvocation`，由 switch 分发，未命中分支用 `satisfies never` 做穷尽检查。
- 通过 `@deepseek-ai/dsh-app-boot` 提供的 `loadOptionalPatches` / `loadOverlayPatches` / `composeEntries` 等函数组合补丁层，而不是直接拼接 YAML。
- 对进程信号（SIGTERM/SIGINT）统一注册中断处理器，结合 AbortController 与 fiber.dispose 保证启动期与运行期的可中断清理。
- 通过相对 `import.meta.url` 定位同包资源（如 `../package.json`、`../config/agent-presets/`），使源码与 lib 产物共用同一份锚点。
- 对外暴露的导出函数采用 `runXxx(options)` 形式，将行为与 CLI 解析解耦，便于测试与 e2e 驱动。
