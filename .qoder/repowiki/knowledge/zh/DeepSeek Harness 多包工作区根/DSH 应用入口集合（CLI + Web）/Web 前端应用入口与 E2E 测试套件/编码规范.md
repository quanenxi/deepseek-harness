- 每个 E2E 场景对应一个 `<name>.e2e.ts` 文件，并在 `tests/snapshots/<scenario>/` 下存放 `.expected.md` / `.jsonl` 等黄金文件，通过 `DSH_SNAPSHOT=refresh` 自动更新。
- 需要覆盖宿主配置的测试通过同名的 `.overlay.yml` 文件（如 `agent-preset-authoring.overlay.yml`、`default-model.overlay.yml`）注入 patch，而非修改测试代码。
- 对 Node-only 模块的浏览器兼容通过 `vite.config.ts` 的 `resolve.alias` + `define` 完成（如 `node:module` → `src/node-module-stub.ts`，`process.versions.node` → `"0.0.0"`），而不是在源码中添加条件分支。
- vendor chunk 成员按 npm 包名白名单声明于 `VENDOR_PACKAGES`，且要求成员包不得直接 import react，避免 React 被折叠进 vendor chunk。
- 测试脚手架统一从 `tests/scaffold.ts` 导出 `launchWebScaffold`/`WebScaffold`，各 e2e 用例通过该接口获取隔离的 `ctx`、`baseUrl`、`workspaceCwd` 和 `whenTurnSettled` 等能力。
