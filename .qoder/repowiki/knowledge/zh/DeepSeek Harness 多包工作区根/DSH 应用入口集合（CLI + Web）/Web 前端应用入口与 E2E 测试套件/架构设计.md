模块由三层组成：
- 运行时入口 `src/main.ts` 是极薄引导，仅通过 `AppWebEntry` 挂载 React 根节点，所有业务逻辑位于 `@deepseek-ai/dsh-client-web` 等 workspace 包中；`vite.config.ts` 通过 `resolve.alias` 将 npm 包名直接指向 `packages/client/*` 的源码，使浏览器侧能走 Vite 管线编译 CSS。
- 构建配置在 `vite.config.ts` 中实现 vendor chunk 拆分（katex/shiki/micromark 等重依赖独立为 `vendor` chunk），并按包名把 `@shikijs/langs` 语法包路由到 `assets/langs/`，KaTeX 字体路由到 `assets/fonts/`；同时用 `rejectStandaloneServe` 插件禁止裸 `vite serve`，强制通过 `dsh web` 注入 `window.__DSH_BOOT__`。
- 测试体系集中在 `tests/`，使用 Playwright + Vitest 启动真实 Chromium，通过 `tests/scaffold.ts` 加载 `packages/bundle/base/cordis.patch.yml` 与 `web-app/cordis.patch.yml` 组装完整 Cordis 上下文，并以 `$DSH_SNAPSHOT=replay|record|refresh` 模式驱动 session.jsonl 回放、录制与黄金文件刷新；`tsconfig.json` 显式排除大量 e2e 文件以避免与 host 侧 tsconfig.host.json 冲突，并通过 `references` 引用 client/web 与 client/modules 类型项目。
- 依赖方向单向：本模块 → `@deepseek-ai/dsh-client-web` 及各类 dsh-* 客户端包，不反向被 shell 以外代码引用；`src/node-module-stub.ts` 作为 `node:module` 的浏览器替身，配合 `define` 替换 `process.versions.node` 以屏蔽 vendored loader 的 Node 探测。
