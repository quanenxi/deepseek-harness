apps 目录仅作为两个独立应用的容器：cli/ 通过 bin.ts 解析参数并分派到 profile-boot、plugin、dump-config 等模块；web/ 通过 vite.config.ts 与 src/main.ts 构建浏览器产物，并由 tests/ 下的 Playwright/Vitest 套件驱动 E2E。两个子应用共享同一套 Cordis 配置约定——profile、preset、agent.cordis.yml 与 agent-presets 目录结构在 cli/config/agent-presets 中提供默认模板，web 的 e2e 测试也复用这些 preset 来注入模型、工具与插件行为，从而保证 CLI 与 Web 运行时的配置语义一致。两者之间无直接代码依赖，仅通过 Cordis 配置契约间接耦合。
