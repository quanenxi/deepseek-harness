本模块由三个并列的包族组成，每个子目录都是一个独立的 npm 包（`@deepseek-ai/dsh-*`），通过 Cordis 插件机制挂载到宿主运行时：

- `packages/interaction/`：面向人机交互能力。`commands` 子包实现 `CommandRuntime`（继承自 `TypertRemoteService`），基于 `ScopedLayers` 维护全局与 agent-scoped 的命令注册表，暴露 `register/list/find/execute` 并通过 `session.append('command/run'|'command/done')` 记录生命周期事件；`user-approval` 提供 `ApprovalService`，按 session 策略（`ask`/`never`）编排答案器水线并追加 `approval/asked`/`approval/decided`/`approval/policy` 审计事件；`user-questions` 提供 `UserQuestionService` 作为单一 UI 提供者桥接；`tool-ask-user` 是模型侧工具，`permission-presets` 提供权限预设。
- `packages/feedback/`：面向反馈持久化。`message-feedback` 的 `MessageFeedbackService` 通过 `storageDomain.open(messageFeedbackDomainSpec)` 打开 KV 表，对每条 put/delete 做版本冲突检测、会话身份校验与 `ensureTargetDurable` 屏障，并以 `success/rejected` 联合返回；`command-feedback` 仅注册 `/feedback` 命令并追加 `feedback/record` 日志事件。
- `packages/guard/`：面向工具调用安全护栏。`repeat-tool-reminder` 在 `tools/post-execute` 上监听，按 agent 维护 WeakMap 链统计连续相同参数调用，达到阈值后以 `{kind:'plugin'}` 源注入提示上下文；`timeout-policy` 包装 `tools/execute`，用 `deadline`/`timeoutOf` 将超时映射为结构化 `TOOL_TIMEOUT` 结果。

依赖方向单向向外：各插件通过 `peerDependencies` 声明对 `@deepseek-ai/cordis`、`@deepseek-ai/dsh-agent`、`@deepseek-ai/dsh-session`、`@deepseek-ai/dsh-tools`、`@deepseek-ai/dsh-typert-protocol` 等核心包的引用，不反向依赖彼此；跨包协作通过 Cordis 事件总线（`ctx.waterfall`/`ctx.on`）、Session 事件与 Storage Domain 完成。
