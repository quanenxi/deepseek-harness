- 每个能力域统一划分为 Service Definition / Service Provider / Consumer 三层，Consumer 仅依赖 Definition 而非具体 Provider
- 插件通过 Cordis 的 `ctx.effect()`、`ctx.on()`、`ctx.waterfall()` 向宿主注册钩子与效果，而非直接调用其他包
- 包以独立 npm 包发布，命名遵循 `@deepseek-ai/dsh-<pkg>` 且归属到现有 group 的 README 表格中
- 对外暴露的能力接口使用 typert 生成的类型图，并通过 runtime registry 在加载时注册
- 每个包的 README 必须包含目的、API、扩展点与 Model Experience 章节，并声明已知限制或延期项
