本模块由六个并列的“能力家族”组成，每个家族内部遵循统一的“服务定义 + 后端实现 + 策略/插件 + 模型工具”分层：
- `packages/util/`：零依赖原子包（brand、home-paths、timeout、output-retention、atomic-write、native-command），仅暴露纯函数或极小原语，无业务语义。
- `packages/typert/`：类型系统基础设施，按职责拆为 `protocol`（协议类型）、`registry`（运行时反射与 schema 注册，暴露 `ctx.typert`）、`loader`（发现 Loader 并注册宿主产物，消费 `ctx.loader`/`ctx.typert`）、`generator`（构建期源码分析→宿主代码生成，含 tsdown 插件）。
- `packages/hooks/`：外部 shell 钩子到 Harness 拦截扩展点的桥接层，`hook-protocol/` 提供共享 wire 协议（codec/matcher/runner/events），`hooks-claude-code/` 与 `hooks-codex/` 各自实现特定方言的事件映射，作为 Cordis 插件注册。
- `packages/fs/`：文件系统栈，`fs/fs/` 定义 `FileSystem` 服务契约与 `fs/*` 事件门；`fs-local/` 提供本地实现；`fs-sandbox/` 在写入路径上施加沙箱围栏；`fs-observation-policy/` 通过监听 `fs/*` 事件实现 read-before-edit 与版本守卫；`tool-fs/` 暴露 `read/write/edit` 工具；`tool-fs-search/` 基于打包的 ripgrep 进程执行搜索，不侵入 provider 契约。
- `packages/storage/`：非会话持久化，`storage/` 连接已注册的 backend 与 typed data forms（`ctx.storage`）；`storage-json/`、`storage-sqlite/` 分别以 JSON 文件与 SQLite 注册 backend；`storage-domain/` 提供带校验的领域记录存储（`ctx.storageDomain`）。
- `packages/spill/`：超大工具输出转储，`spill/` 定义 `SaveTextSpill` 接口（`ctx.spillStore`），`spill-local/` 落盘到会话目录，`spill-policy/` 在 `ctx.tools` 上监听执行结果并触发转储。
- `packages/compaction/`：消息压缩能力，`compaction/` 定义 seam 与事件词汇（`ctx.compaction`），`compaction-basic/` 提供 token 压力与摘要后端，`compaction-tool-result-pruner/` 是可选的模型无关结果裁剪器，`command-compact/` 暴露人类命令。
所有包均遵循相同的目录布局（`src/`、`lib/`、`tests/`、`package.json`、`tsconfig.json`），并通过 Cordis 上下文键（`ctx.*`）进行服务装配，依赖方向严格自底向上：协议/契约 → 后端实现 → 策略/插件 → 模型工具。
