本模块由三个按依赖方向自底向上组织的子能力组成：
- `packages/subprocess`：最底层，定义 `SubprocessRuntime` 抽象服务（`ctx.subprocess`），暴露可执行解析、普通进程 spawn、PTY 原生 spawn 及句柄生命周期；`subprocess-local` 作为本地 Provider，基于 `node-pty`、前台进程组、进程树信号与终止级联实现。
- `packages/shell`：在 subprocess 之上定义 `ShellExecutor` 抽象服务（`ctx.shell`），统一 foreground run / background start / resolve 语义，并派生 `bash-local`、`bash-sandbox`、`pwsh-local`、`pwsh-sandbox` 四种实现（本地或沙箱 + POSIX 或 Windows PowerShell）；`shell-env` 提供共享的 `DSH_*` 环境变量；`tool-bash`、`tool-pwsh` 将执行能力暴露为模型工具。
- `packages/terminal`：独立于 shell 的持久 PTY 能力，`terminal` 包定义 `TerminalSessionService`（`ctx.terminals`）作为后端无关的注册表，维护 owner-scoped 会话、名称预留、并发 send 互斥与优雅清理；`terminal-bash` 通过 `ctx.subprocess.spawnTerminal` 实现 Bash PTY 后端；`tool-terminal` 暴露六个模型工具用于发送、读取、信号与等待。
依赖方向严格单向：terminal → subprocess；shell 仅依赖 subprocess 与 sandbox（类型）；各 tool-* 包消费 shell 或 terminal 的服务接口并通过 cordis 插件机制挂载到 `ctx.tools`。所有服务均继承 `@deepseek-ai/cordis` 的 `Service`，通过扩展 `Context` 接口注入键名（`ctx.shell`、`ctx.subprocess`、`ctx.terminals`），并以 `src/invariant.ts` 统一运行时断言。
