- 插件统一以 `export const name`、`export const inject = [...]`、`export function apply(ctx, config)` 三件套暴露，供 Cordis 框架发现与挂载。
- 对外暴露的配置对象通过 `schemastery` 的 `z.object({...})` 声明并附带默认值，同时在 `apply` 或构造函数中对未走 schema 的路径做二次校验。
- 错误统一封装为带稳定 `code` 字符串的 `LlmError`（如 `DUPLICATE_ADAPTER`、`MISSING_CREDENTIAL`、`INVALID_PREPARED_CALL`），便于调用方按机器码分支处理。
- Provider 路由注册返回可处置句柄（`AdapterRegistrationHandle`/`DirectoryRegistrationHandle`），其 `replace()` 方法先全量校验候选集再原子替换，避免中间态暴露给并发请求。
- 运行时状态变更通过 `ctx.events.dispatch('emit', ...)` 非阻塞广播（如 `llm/adapters-updated`、`skills/change`），并在循环中 try/catch 单个 listener 以防一个失败中断后续通知。
- 流式调用统一经 `ctx.waterfall(this, 'llm/stream', options, () => adapterStream(...))` 包装，使重试、重放、路由等横切逻辑可在同一拦截点叠加。
