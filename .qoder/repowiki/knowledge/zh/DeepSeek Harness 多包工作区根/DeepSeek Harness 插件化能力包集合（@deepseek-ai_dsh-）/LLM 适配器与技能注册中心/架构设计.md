本模块由两个并列的包族组成，均基于 @deepseek-ai/cordis 的 Service/Context 扩展模型。

- `packages/llm`：核心抽象层 `@deepseek-ai/dsh-llm`（`src/index.ts` 暴露 `LlmRuntime`、`LlmAdapter`、`BlockAssembler`、`LlmError`），通过 `ctx.llm.registerAdapter()` / `registerConfigurableProviders()` / `registerModelDiscovery()` 维护 provider→adapter 路由表，并以 `llm/stream` waterfall 事件作为所有流式调用的拦截点；配置解析、API Key 校验、重试策略、消息冻结等横切逻辑集中在该包内，保证下游适配器零依赖。
- `packages/llm` 下的具体实现包：`llm-deepseek` 直接对接 DeepSeek HTTP 接口，`llm-pi-ai` 通过 pi-ai SDK 适配 OpenAI/Anthropic 等协议，两者都遵循 `LlmAdapter.stream` 契约并通过 `apply(ctx, config)` 挂载到 `ctx.llm`；`llm-retry` 监听 `agent/request-error` 按 provider 维度的 `ResolvedRetryPolicy` 执行指数退避；`token-meter` 订阅 `session/event` 流，结合 `BlockAssembler` 对会话回放进行 Token 用量估算与压力投影。
- `packages/skill`：`skill` 包定义 `SkillRegistry`（`src/index.ts`）作为 Skill Provider 注册中心，采用 `ScopedLayers` 实现全局/作用域分层合并，暴露 `list/get/snapshot` 并广播 `skills/change` 事件；`skill-filesystem`、`skill-badge` 是具体 Provider；`tool-skill` 在 `agent/pre-step` 钩子中注入模型可见的 `<available_skills>` 目录，并提供 `skill` 工具以按需加载完整指令体，同时支持 `/name` 用户手势自动注入。

依赖方向单向：`llm-*` 实现 → `@deepseek-ai/dsh-llm` 抽象；`tool-skill` → `skill`；各包之间无横向耦合，仅通过 Cordis Context 服务名（`llm`、`skills`、`agents`、`tools`）通信。
