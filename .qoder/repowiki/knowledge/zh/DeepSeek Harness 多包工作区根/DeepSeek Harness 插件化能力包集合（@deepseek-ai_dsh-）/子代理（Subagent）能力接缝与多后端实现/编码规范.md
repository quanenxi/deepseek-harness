- 后端实现以 `export const name` + `export const inject = [...]` + `export function apply(ctx, config)` 的 Cordis 插件形态暴露，并在 `apply` 中调用 `ctx.subagents.registerProvider(...)` 完成注册。
- Provider 通过 `capabilities` 对象声明支持的 start 时特性（`outputSchema`/`depthLimit`/`toolFilter`/`persona`），由 `SubagentRuntime.assertCapabilities` 在派发前校验，缺失则抛出 `UNSUPPORTED_CAPABILITY` 错误，遵循 fail-loud 原则。
- 所有对外错误统一通过 `SubagentError` 抛出，并携带语义化的 code（如 `NO_PROVIDER`、`CONTINUATION_UNAVAILABLE`、`CANCELLED`），便于上层按码分支处理。
- 可延续子代理的创建被拆分为 provider 的 `prepareContinuable`（返回纯数据 `ContinuableCreateSpec`）与 `SubagentContinuationManager` 的生命周期所有权分离，provider 永远不持有 child 的 `AgentHandle` 或参与 turn 调度。
- 配置校验统一使用 Schemastery (`z.object({...}).default(...)`) 声明默认值与约束，并在 `apply` 中对数值范围（如 dispose grace）做运行时断言。
- 生命周期事件通过 scoped `LifecycleEmitter` 发布，并以 `scopeTarget(this, parent)` 绑定 carrier，使 `subagent/start` 与 `subagent/end` 成对到达相同作用域监听者。
