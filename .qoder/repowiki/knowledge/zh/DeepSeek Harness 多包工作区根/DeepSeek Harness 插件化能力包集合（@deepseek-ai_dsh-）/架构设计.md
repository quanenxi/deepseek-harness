packages/ 是 Harness 的插件仓库，每个子目录发布为独立的 `@deepseek-ai/dsh-*` npm 包，由 core_runtime 中的 Cordis Loader 在启动时扫描并装载。跨包协作遵循统一的「能力接缝」约定：每个能力域（如 shell、terminal、fs、lsp、web、subagent、jobs、workflow、session、llm 等）都分离为 Service Definition（抽象契约）、Service Provider（具体实现）与 Consumer（模型侧工具或上层服务），使 dsh-agent-loop 可被替换且 UI/hook/tool 插件仅依赖抽象。核心运行时通过 `ctx.effect()`、`ctx.on()`、`ctx.waterfall()` 注册钩子与效果，会话持久化、设置、凭据、身份、工作区等横切能力由 shared_libs 提供，client_api 暴露浏览器 GUI 与 SDK 边界，support_assets 提供测试与示例。依赖图由 CI 自动生成并冻结，新增包需加入对应 group README 的 table。
