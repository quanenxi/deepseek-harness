- 每个包遵循 src/lib 双目录结构：源码在 src/，编译产物在 lib/，并在 package.json 中通过 exports 字段同时暴露主入口与 ./invariant 路径。
- 所有包均附带 README.md、README.zh.md、README.i18n.yaml 三语文档，保持多语言说明同步。
- 测试用例与 fixtures 放在 tests/ 目录下，fixture 采用行为驱动的子目录命名（behavior.json + input.json + session.jsonl + stdout.expected.jsonl）。
- 对外 API 通过 index.ts 显式 re-export，内部类型以 type-only 形式导出，避免泄漏内部实现细节。
- 错误处理统一通过自定义 Error 类（如 AttachmentError）与 invariant 断言配合，保证调用方可区分业务错误与契约违反。
