- 每个子包采用 src/lib/tests 三目录结构，并通过 tsdown 同时产出 lib 与 types 产物。
- 跨环境共享的包统一提供 client/host 双 tsconfig，使同一源码可同时编译到浏览器与宿主环境。
- API 层通过 ctx 键（如 ctx.typert、ctx.remote、ctx.web、ctx.tools）进行服务注入，避免直接 import 具体实现。
- UI 功能以 ui- 前缀命名独立包，并通过 slot 系统声明扩展点与消费关系。
- 每个子包附带 README.md、README.zh.md、README.i18n.yaml 三份多语言文档。
- 每个子包在 src 下提供 invariant.ts 并在运行时抛出结构化错误，tests 目录存放单元与 e2e 用例。
