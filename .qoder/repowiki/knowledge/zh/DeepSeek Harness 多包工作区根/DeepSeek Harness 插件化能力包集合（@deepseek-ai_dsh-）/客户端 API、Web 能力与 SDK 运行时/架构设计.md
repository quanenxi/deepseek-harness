本模块由四个相互独立的子包域组成，各自通过 Cordis 服务注入与契约类型解耦：
- `packages/client`：浏览器侧 dsh Web GUI，按职责拆分为基础层（connection/hmr/locale/runtime/modules）、UI 原子与页面（ui-primitives、ui-layout、ui-sidebar、ui-conversation、ui-tool 等）以及入口（web/web-react），通过 slot 系统注册 UI 扩展点并由 modules 加载。
- `packages/api`：应用面向的 Remote 栈，`remotes` 实现 BFF 策略与 Agent/Session 查找，`gateway` 暴露 Typert 单向 RPC 端点；依赖方向严格为 remotes → gateway → connection → webserver，通过 ctx.typert / ctx.remote / ctx.typertGateway 注入而非直接 import。
- `packages/web`：提供 provider-neutral 的 Web 能力族，`web` 定义注册/选择接口并挂载到 `ctx.web`，各 search/fetch 插件（exa/perplexity/deepseek/http）以相同方式注册，`tool-web` 将能力暴露给模型工具层。
- `packages/sdk`：跨进程驱动 Harness 运行时的协议栈，`protocol` 定义 wire 协议与 transport，`client` 提供 TS 调用方，`server` 通过 stdio JSON-RPC 对外提供服务。
所有子包均使用 tsdown + 双 tsconfig（client/host）构建产物，并通过 README.i18n.yaml 维护多语言文档。
