- 每个子包以 `src/index.ts` 暴露主类/函数，并通过 `declare module '@deepseek-ai/cordis' { interface Context { ... } }` 向 Context 扩展注入键（如 `sessionReferenceResolver`、`settings`、`agentPresets`）。
- 配置对象统一使用 Schemastery (`z.object(...)`) 声明，并以 `static Config` 或模块级常量形式暴露，同时提供 `DEFAULT_*` 常量与自定义错误类型。
- 每个子包配套 `src/invariant.ts` 与 `tests/invariant.spec.ts`，用 invariant 断言保证运行时不变量，测试覆盖该不变量。
- 设置写入走序列化写队列：`update`/`replace`/`mutate` 都进入 `write()`，通过 `expectedRevision` 检测并发冲突并抛出 `SettingsConflictError`。
- Preset 采用“站立式 mount + 文件 stamp 失效”模式：`ensureStanding` 缓存按 preset id 的单飞 Promise，比较 mtimeMs+size 决定是否重建生成，避免频繁重新组合。
- 对外部输入一律先做 JSON 形状克隆与校验（`cloneJsonShaped`、`isPlainObject`），拒绝 Date/Map/BigInt/循环引用等非 JSON 值后再落盘。
