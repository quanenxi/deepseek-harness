本模块由三个并列的能力族组成，均基于 @deepseek-ai/cordis 的 Service/Context 机制并通过 Context 扩展注入键：
- `packages/context`：四个独立子包各自注册一个能力——`session-reference` 通过 `SessionReferenceResolver` 服务将其他会话的快照投影为不可信只读提示；`time-context` 暴露当前时间与耗时；`tmux-context` 注入 tmux 位置；`agent-instructions` 聚合工作区指令。每个子包遵循 src/invariant.ts + tests/*.spec.ts 的结构，并导出到 `ctx.sessionReferenceResolver`、`ctx.settings` 等键。
- `packages/settings`：`settings` 子包定义抽象基类 `SettingsProvider`，实现命名空间注册、三层合并（schema 默认值 → composition base → 用户层）、序列化写队列、revision 冲突检测、watcher 串行回调与 `settings/document-updated` 事件；`settings-file` 作为具体 Provider 把文档持久化到本地文件并监听外部编辑。消费者通过 `installSettingsSection` 在 settings 存在时自动挂载、缺失时回退到 entry。
- `packages/preset`：`agent-presets` 子包维护进程级“站立式”mount 缓存（按 preset id 单飞），通过文件系统发现 trusted/user 根下的 `agent.cordis.yml`，用 dsh-scope 的 `bindScopeParent` 把 agent scope 挂到 preset 的 standing scope key 上，从而让多个 agent 共享同一份工具/提示注册；`persona` 仅暴露 persona 行类型。`AgentPresets` 还通过 `installSettingsSection` 订阅 `agent-presets` 命名空间的默认 preset 选择。
依赖方向单向：preset 依赖 settings（读取默认 preset），context 各子包彼此独立，都不反向依赖 preset。
