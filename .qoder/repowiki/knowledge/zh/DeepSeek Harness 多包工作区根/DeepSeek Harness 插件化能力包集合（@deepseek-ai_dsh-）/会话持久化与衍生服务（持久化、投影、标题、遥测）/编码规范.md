- 每个能力包通过 `declare module '@deepseek-ai/cordis' { interface Context { ... } }` 向全局 Context 注入服务键（如 `sessionPersistence`、`sessionProjections`、`sessionTitle`、`sessionTelemetry`），并在 `src/index.ts` 中导出默认 Service 类。
- 持久化/投影/标题等服务均继承 `Service` 基类，构造函数中通过 `super(ctx, name)` 注册服务名，并使用 `ctx.effect` 管理生命周期清理。
- 对外暴露的错误类型统一自定义 Error 子类并设置稳定 `name`（如 `SessionPersistenceCorruptionError`、`SessionFormatUnsupportedError`、`SessionTitleInvalidError`），以便调用方精确识别。
- 可插拔实现通过接口+注册模式：后端实现 `PersistenceBackend`、标题生成实现 `SessionTitleProvider`、遥测实现 `SessionTelemetrySink`，由宿主装配时注入。
- 投影单元遵循纯函数约定：`apply(state, event)` 必须同步且返回新引用时才触发下游通知，`stateVersion` 用于缓存失效，`view` 输出经 Zod schema 校验后发布。
- 异步工作流通过 `AbortSignal` 传递取消信号，并在关键路径（如 `prepare`、`inspect`、`refresh`、provider.generate）开头调用 `signal?.throwIfAborted()` 或 `signal.throwIfAborted()` 快速失败。
