- 每个子包遵循 `src/index.ts` 作为主入口、`src/invariant.ts` 暴露运行时不变量断言、`lib/` 存放编译产物的目录结构。
- 对外暴露的服务类通过 `static inject = [...]` 声明依赖，并在构造函数中通过 `ctx.inject(['optionalFeature'], cb)` 以可选 child 方式挂载命令或投影，使插件在无对应宿主时仍可加载。
- 状态变更统一通过向 `session.append('xxx/event', payload)` 追加不可变事件实现，读取端用纯函数 fold（如 `foldPlanMode`、`foldGoal`）从事件流重建视图，保证可重放与 fork/resume 一致。
- 所有公开 API 的参数在进入领域层前由独立的 `resolveXxx` 函数进行 Zod 校验并抛出结构化错误，失败发生在插件加载或调用边界而非业务逻辑内部。
- 阶段转换方法集中封装为 `transition(agent, ref, operation, allowed, phase, activation)` 形式，配合 `transitionError` 生成稳定错误码，避免分散的条件分支。
- 对进程内缓存使用 `WeakMap<Session, Cache>` 存储 per-session 状态，并在 `agent/session-start` 等生命周期事件中重置，确保 agent 回收时内存自动释放。
