模块由两个并列子包构成：`packages/plan/plan-mode` 实现 `PlanModeController`，基于 `sessionProjections` 注册 `plan` 投影（last-wins 的 `plan/mode` 事件 + `command/run plan` 选择），在 `agent/pre-step` 边界追加状态变更并通过 `systemPrompt.section('plan:policy')` 注入引导文本，同时暴露稳定的 `exit_plan_mode` 工具与 `/plan` 命令；`packages/goal` 下进一步拆分为四个子包——核心领域 `goal/goal` 通过 `GoalService`（继承 `TypertRemoteService`）维护事件溯源的目标状态机（active/paused/blocked/complete），以 `goal/change` 事件写入 session 日志、按 revision 做 compare-and-set，并导出 `foldGoal`/`applyGoalProjection` 供外部重放；`tool-goal` 暴露 `get_goal/create_goal/update_goal` 三个模型工具，内置人类意图校验与 `blockedAfterConsecutiveRounds` 策略；`command-goal` 提供 `/goal` CLI 入口；`goal-round-driver` 监听 `goal/changed` 并在 agent idle 时自动推进下一轮，使用 `RoundAttempt` 队列与 `validReservation` 围栏保证消息不丢失、不重复，达到上限后回写 blocked 状态。各子包通过 `@deepseek-ai/cordis` 的 `inject`/`effect`/`on` 机制组合，依赖方向单向：driver → goal service → session log，plan-mode 与 goal 子系统仅通过共享的 session event 类型耦合。
