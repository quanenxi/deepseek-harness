- 每个包通过 `declare module '@deepseek-ai/cordis'` 扩展 Context 接口（如 `workspaceRegistry`、`sandbox`、`sandboxPolicy`），将服务挂载为上下文属性而非全局单例。
- Service 类统一通过 `static Config: z<...>` 声明式配置 schema 并提供默认值，构造函数中对配置做运行时断言（如 `assertPositiveFinite`、非空签名检查）。
- 对外错误类型继承 `HarnessError` 或自定义 Error 并设置 `this.name`，通过结构化错误码（如 `SANDBOX_UNAVAILABLE`）区分后端不可用与命令失败。
- 跨后端契约通过共享类型（`SandboxMode`、`SandboxPolicy`、`ConfinedArgv`、`RunnerFailureRule`）约定，各后端只实现自身方言（denialSignatures、runnerFailureRules），消费者按后端返回的 dialect 匹配 stderr。
- 资源清理采用 `ctx.effect(() => () => revokeAclGrants(), ...)` 注册副作用钩子，确保 provider 析构时释放临时目录、SID 与 ACL grant，且清理失败聚合为 `AggregateError` 上报而不中断主流程。
- Windows ACL 后端严格区分 standing workspace grant（跨会话复用、永不撤销）与 revocable temp grant（随 provider 销毁撤销），并通过确定性 `workspaceWriteSid` 派生实现 exact-ACE 跳过优化。
