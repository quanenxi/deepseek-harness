- 通过 Cordis 的 `Service` 基类扩展抽象契约，并以 `new.target === JobRegistry` 在构造期拒绝直接实例化抽象类，强制消费方加载具体实现。
- 对外暴露的类型集中在 `types.ts`，并通过 `export type { ... }` 从入口重新导出，保持 API 表面与内部实现解耦。
- 作业访问控制统一通过 `assertAccess(job, caller)` 比较 `job.owner.id` 与 `caller?.id`，实现基于 session id 的所有权围栏。
- 监听器与控制器按作用域分层注册：使用 `ScopedLayers` + `AnonymousEntries`，并通过 `layers.effect(ctx, appendFn, { label })` 返回 disposer，保证 effect 作用域退出时自动清理。
- 作业快照一律通过私有 `snapshot(job)` 投影生成新对象，避免向外部暴露可变内部状态。
- 完成通知与变更通知采用 first-wins 语义：先标记 terminal、释放 waiters、再通知 `onJobsChanged`，最后才遍历 `listenersFor(owner)` 调用 `onJobDone`，确保其他观察者已看到提交后的记录。
