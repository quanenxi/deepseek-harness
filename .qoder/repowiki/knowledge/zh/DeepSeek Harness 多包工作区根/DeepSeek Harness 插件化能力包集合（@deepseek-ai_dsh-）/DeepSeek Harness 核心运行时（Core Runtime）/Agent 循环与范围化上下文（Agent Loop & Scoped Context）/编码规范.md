- 通过 Cordis `Service` 扩展 `Context` 接口（如 `ctx.agents`、`ctx.agentLoop`）并以 effect 形式注册生命周期清理回调。
- 使用 `AbortController`/`AbortSignal` 组合多个取消源（调用方信号、工厂 teardown、owner fiber 卸载）来统一中断长生命周期操作。
- 对外暴露的工厂方法返回 `AgentHandle { agent, dispose }`，将销毁能力限制在句柄持有者手中，而内部通过 registry 结构性地管理 teardown。
- 所有配置项通过 `schemastery` 的 `z.object(...)` schema 声明并附带默认值与最小值校验，运行时再二次验证数值范围。
- 事件分发统一通过 `ctx.events.dispatch('emit', args)` 遍历监听器并用 try/catch 包裹，避免单个 listener 失败污染整体流程。
- 通过 `scopeTarget(base, key)` 包装 subject 并配合 `scopeOf(ctx)` 在事件路由中仅允许父作用域接收子作用域事件，禁止反向传播。
