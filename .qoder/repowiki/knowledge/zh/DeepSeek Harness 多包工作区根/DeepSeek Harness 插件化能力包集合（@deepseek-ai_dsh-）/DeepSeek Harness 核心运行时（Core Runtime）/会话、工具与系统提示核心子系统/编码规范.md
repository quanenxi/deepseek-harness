- 所有对外暴露的 Service 通过 `declare module '@deepseek-ai/cordis'` 扩展 `Context` 接口，将服务挂载为 `ctx.sessions`、`ctx.tools`、`ctx.systemPrompt`。
- 通过 `ctx.emit('...')` 定义 scoped 事件总线（如 `session/event`、`tools/pre-execute`、`system-prompt/assemble`），并在 JSDoc 中用 `@mode waterfall` / `@mode emit` 标注分发语义。
- 跨边界数据进入时统一调用 `snapshotJsonValue` 进行 lossless JSON 序列化校验，随后对不可变对象使用 `deepFreeze` 或栈式 `freezeRestoredObject` 冻结。
- 注册表采用 `ScopedLayers` + 自定义 Layer 类（`ToolLayer`、`PromptLayer`）实现全局与作用域叠加，重复名称通过 `NamedEntries` 抛出带作用域信息的错误。
- 配置对象使用 `z.object({...}).default(...)` 在 `static Config` 上声明，并在构造函数中以默认值兜底可选字段。
- 错误通过继承 `HarnessError` 的专用类表达（如 `SessionForkError`、`ToolNotFoundError`、`ToolOutputError`），携带结构化 `code` 以便上层路由区分。
