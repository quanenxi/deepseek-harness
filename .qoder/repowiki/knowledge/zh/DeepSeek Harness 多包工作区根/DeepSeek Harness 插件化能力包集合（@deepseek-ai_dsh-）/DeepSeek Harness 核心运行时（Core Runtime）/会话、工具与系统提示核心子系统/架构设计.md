本模块由三个相互协作的独立 npm 包组成，均通过 Cordis `Service` 注入到上下文：
- `@deepseek-ai/dsh-session`（packages/core/session）：以 `Session` 类维护 append-only 事件日志，通过 `SurfaceManager` 维护有序 surface 节点并派生 LLM 消息历史；`SessionStore` 作为内存 store，暴露 `create/prepare/enter/announce` 生命周期，并通过 Cordis 事件 `session/created`、`session/event`、`session/flush`、`session/disposed` 与持久化插件解耦。关键文件：`src/index.ts`（Session/SessionStore）、`src/surface.ts`（surface 投影）、`src/request-header.ts`、`src/chunk-rows.ts`、`src/preparation.ts`、`src/repair.ts`。
- `@deepseek-ai/dsh-tools`（packages/core/tools）：`ToolRuntime` 实现工具注册、作用域分层（`ScopedLayers` + `ToolLayer`）、预执行/around-dispatch/后执行水线（`tools/pre-execute`、`tools/execute`、`tools/post-execute`、`tools/result`），并提供 native/code/both 三种模型呈现模式，内置 `run_code` 传输工具。依赖 `dsh-system-prompt` 获取 schemas，依赖 `dsh-session` 做 JSON 快照。关键文件：`src/index.ts`、`src/schema.ts`、`src/json-schema.ts`、`src/code-mode.ts`、`src/presentation.ts`、`src/ts-types.ts`、`src/py-types.ts`。
- `@deepseek-ai/dsh-system-prompt`（packages/core/system-prompt）：`SystemPrompt` 维护按 order 排序的 sections、contexts、tool providers 和 variables，通过 `assemble()` 合并全局与作用域层，运行 `system-prompt/assemble` 水线，并以严格 `{{variable}}` 语法渲染最终 prompt。被 tools 用于生成 tool schema 列表。
依赖方向：tools → system-prompt；session 不依赖另外两个；三者都依赖 `@deepseek-ai/cordis`、`@deepseek-ai/dsh-scope`、`@deepseek-ai/dsh-invariants`、`@deepseek-ai/dsh-llm`。
