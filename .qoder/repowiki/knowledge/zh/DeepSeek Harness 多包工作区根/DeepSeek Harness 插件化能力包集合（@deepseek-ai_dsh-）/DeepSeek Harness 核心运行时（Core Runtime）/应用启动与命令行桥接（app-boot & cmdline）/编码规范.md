- 对外 API 以具名函数形式从 `index.ts` 集中导出，并在 `package.json` 的 `exports` 字段中显式声明 `.` 和 `./invariant` 入口，类型定义输出到 `lib/types/`。
- 所有面向用户的错误消息统一以 `${binName}: ...` 前缀开头，便于在多二进制环境中定位来源。
- 通过扩展 `@deepseek-ai/cordis` 的 `Context` 接口（`declare module`）来注入宿主提供的服务键（如 `dshHomePath`、`cmdlineArgs`、`appExit`），而非新增全局对象。
- 对可选依赖（如 HMR）采用运行时探测（`ctx.get('hmr') === undefined` 抛错）而非编译期条件，使包在无 HMR 环境下仍可正常 boot。
- 配置文件读取采用「先解析校验、后生效」的两阶段模式（如 `readEnvLayer`、`parsePatchList`），确保任何一层的非法输入不会污染已生效的环境或配置。
- 通过 WeakMap（如 `bootstrapIncludes`）将临时启动期对象与 Context 生命周期绑定，避免全局泄漏并在上下文销毁时自动清理。
