- 路由注册 API 统一返回 disposer 函数，调用方负责在 fiber 卸载时对称移除，确保路由表与生命周期一致。
- 重复注册同一 (kind, path) 直接 throw Error，将冲突视为组合期 misconfiguration 而非静默覆盖。
- 请求与 upgrade 处理路径全部包裹 try/catch，异常经 `ctx.logger.warn/error` 记录后返回 400 或销毁 socket，保证单请求失败不导致进程退出。
- 对外暴露的公共类型（`WebRouteKind`、`WebRoute`、`WebUpgradeRoute`、`Config`）在文件顶部集中定义并通过 `export interface/type` 导出，配合 schemastery 的 `z.object` 做运行时校验。
- 通过扩展 `@deepseek-ai/cordis` 的 `Context` 模块声明注入 `webServer` 服务，使其他插件能以类型安全方式获取该服务实例。
