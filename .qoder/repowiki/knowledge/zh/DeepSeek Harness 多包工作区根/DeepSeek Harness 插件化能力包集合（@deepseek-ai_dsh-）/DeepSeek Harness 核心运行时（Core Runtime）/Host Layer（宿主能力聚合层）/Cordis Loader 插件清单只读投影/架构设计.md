模块以 `src/index.ts` 中的 `PluginInventoryGateway`（继承自 `@deepseek-ai/dsh-typert-protocol` 的 `TypertRemoteService`）为唯一入口，在构造时注册名为 `pluginInventory` 的服务，并通过 `@Remote('list')` 装饰器暴露 `list()` 方法；每次调用直接遍历 `ctx.loader.entries()` 跳过 group 条目并映射为 `PluginInventoryEntry`，不维护任何缓存或事件订阅，保证 Loader 作为唯一生命周期权威。

类型层位于 `src/types.ts`，使用 `@deepseek-ai/dsh-brand` 的 `Branded<'PluginEntryId'>` 对字符串 ID 进行品牌化，并将 Cordis 内部 `FiberState` 常量枚举映射到外部可见的 `PluginFiberPhase` 字面量联合（含 `null` 表示无根 Fiber）。

构建产物通过 `package.json` 的 `exports` 字段拆分多个子路径：`.` 导出网关类，`./invariant` 导出包级不变量安装器，`./types` 导出纯类型，`./typert` 和 `./remote` 由 Typert 生成的 Host/Client 远程工件（位于 `lib/`），供客户端消费。

依赖方向单向向外：仅依赖 `@deepseek-ai/cordis`、`@deepseek-ai/dsh-brand`、`@deepseek-ai/dsh-invariants`、`@deepseek-ai/dsh-typert-protocol` 与运行时 `zod`（由生成代码引入），peer/devDependencies 声明了 workspace 内相关包以便测试与类型检查。
