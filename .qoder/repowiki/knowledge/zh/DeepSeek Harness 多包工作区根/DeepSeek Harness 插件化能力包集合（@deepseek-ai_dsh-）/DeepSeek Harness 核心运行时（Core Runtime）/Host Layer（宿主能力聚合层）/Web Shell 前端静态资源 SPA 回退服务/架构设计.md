模块以 Cordis 插件形式暴露两个入口：`src/index.ts`（主插件 `frontend-static`）通过声明 `inject = ['webServer']` 依赖宿主 webserver，在 `apply(ctx, config)` 中调用 `ctx.webServer.registerFallback` 注册一个仅处理 GET/HEAD 的回退处理器；`src/invariant.ts`（`host-frontend-static-invariant`）作为空实现的 invariant companion，向 `@deepseek-ai/dsh-invariants` 注册包名以参与生命周期探测。核心逻辑集中在 `serveStatic(pathname, res, distRoot, distIndex, renderIndex)`：先通过 `resolve + normalize + startsWith(distRoot + sep)` 防御路径穿越，再区分根路径与 `distIndex` 走 `renderIndex()`（经 `ctx.webServer.applyIndexTaps` 注入 boot-manifest），其余路径尝试 `readFile` 并以 MIME 表映射 content-type，未知扩展降级为 `application/octet-stream`，读取失败则回退到 index.html 实现 SPA 路由。配置使用 `@deepseek-ai/schemastery` 的 `z.object({ distIndex: z.string().required() })` 校验，构建产物位于 `lib/`，并通过 `package.json` 的 `exports` 同时暴露 `.` 与 `./invariant` 子路径。
