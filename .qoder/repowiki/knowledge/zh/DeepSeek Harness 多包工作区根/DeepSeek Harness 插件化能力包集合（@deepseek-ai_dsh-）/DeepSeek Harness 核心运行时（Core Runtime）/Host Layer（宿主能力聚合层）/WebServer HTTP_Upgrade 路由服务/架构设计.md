模块以 `src/index.ts` 中的 `WebServer` 类为核心，继承自 `@deepseek-ai/cordis` 的 `Service`，在 `[Service.init]` 中创建 `node:http.Server` 并立即监听；请求处理通过内部 `match()` 按“精确表命中优先 → 最长前缀匹配”策略分派到 `exact`/`prefixes` Map，未命中的请求由可选的 `fallback` 处理器（SPA dist 静态服务）或 404 响应。

- 路由注册：`register()` 管理精确/前缀 HTTP 路由，`registerUpgrade()` 管理 exact-path 的 HTTP Upgrade 路由（如 WebSocket），均返回 disposer 以支持 fiber 卸载时对称清理。
- 升级连接追踪：所有被接受的 upgraded socket 加入 `upgradedSockets` Set，在服务 teardown 时通过 `effect` 显式 destroy，因为 Node 的 `closeAllConnections` 不包含已升级 socket。
- 索引变换：`tapIndex()` 注册纯函数管道，由 fallback 所有者在渲染 index.html 时通过 `applyIndexTaps()` 顺序应用。
- 错误隔离：每个请求和 upgrade 路径都包裹 try/catch，异常记录日志后返回 400 或销毁 socket，绝不抛出进程级失败。
- 配置校验：通过 `schemastery` 的 `z.object` 声明 `Config` schema，限制 host 为 `127.0.0.1`/`0.0.0.0`，port 为自然数。
- 不变量守护：`src/invariant.ts` 暴露 `apply` 作为 `@deepseek-ai/dsh-invariants` 的 companion plugin，在每次 cordis `internal/plugin` 事件时用保留路径 `__dsh_invariant_probe__` 探测 register/dispose 对称性，防止路由泄漏。
- 包导出：`package.json` 将 `.` 指向 `lib/index.js`，`./invariant` 单独导出不变量安装器，`./src/*` 暴露源码用于测试直连。
依赖方向单向向外：仅依赖 `@deepseek-ai/cordis`（上下文与服务框架）、`@deepseek-ai/schemastery`（配置校验）、`@deepseek-ai/dsh-invariants`（可选不变量），不感知 harness 业务概念。
