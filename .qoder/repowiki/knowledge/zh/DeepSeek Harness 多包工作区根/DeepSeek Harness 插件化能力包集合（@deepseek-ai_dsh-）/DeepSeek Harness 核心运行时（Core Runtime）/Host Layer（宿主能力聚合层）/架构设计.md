本模块以 packages/host/ 为容器，按职责拆分为多个独立的 npm 子包：api_proxy 通过 RpcMap + Schema 暴露跨进程 RPC 网关；directory_picker 及其三个实现（auto/browse/native）提供可插拔的目录选择策略；webserver 提供 HTTP/WebSocket 路由服务；frontend_static 提供 SPA 静态回退；plugin_inventory 暴露插件清单快照。各子包均遵循统一的 Cordis Service 模式——每个包导出一个 index.ts 入口并附带 invariant.ts 运行时守卫，由宿主进程在启动时按需加载并注册到 Cordis 上下文，从而让上层应用通过 ctx.* 访问这些宿主能力。子包之间不直接互相依赖，而是通过宿主进程在启动阶段进行装配组合。
