- Cordis 插件统一导出 `name`、`inject`、`apply`（以及可选的 `Config` schema），由宿主按约定加载。
- 对外暴露的配置对象均配套一个同名的 `schemastery` Zod schema（如 `Config`），用于运行时参数校验。
- 静态资源响应通过集中式 `MIME` 映射表决定 `content-type`，未知扩展统一降级为 `application/octet-stream`。
- 对文件系统访问前先用 `resolve + normalize + startsWith(distRoot + sep)` 进行路径穿越校验，拒绝后直接返回 403。
