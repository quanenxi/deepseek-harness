- 对外暴露的标识符通过 `Branded<T>` 包装（如 `PluginEntryId`），在边界处用工厂函数转换原始字符串，避免裸字符串泄漏。
- Cordis 内部 const enum（如 `FiberState`）在包边界映射为公开的字面量联合类型（如 `PluginFiberPhase`），保持跨包契约稳定。
- Remote 服务通过继承 `TypertRemoteService` 并在构造函数中指定服务名，再以 `@Remote('method')` 装饰器声明可远程调用的方法。
- 每个包提供独立的 `invariant.ts` 配套模块，遵循 `name`、`inject`、`install`、`apply` 固定结构向 `dsh-invariants` 注册包级不变量。
- 公共类型集中在 `src/types.ts`，并通过 `export type * from './types.ts'` 从主入口重新导出，使消费者可同时获得类型与运行时实现。
