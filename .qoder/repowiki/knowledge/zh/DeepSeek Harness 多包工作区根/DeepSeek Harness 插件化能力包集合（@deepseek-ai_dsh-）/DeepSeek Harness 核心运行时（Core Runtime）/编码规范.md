- 每个子包遵循 src/lib 双输出结构，src 下每个文件配套 invariant.ts，测试位于 tests/ 并与源码同名对应。
- 宿主能力通过 Cordis Service 类暴露，使用静态 inject 数组声明依赖的服务名，而非直接 import core 模块，保持 transport-agnostic。
- API 契约以 api/*.schema.ts + *.ts 成对定义，Zod schema 与类型同步导出，供 host 与客户端共享。
- 配置项一律用 Zod object 描述默认值与约束，并在 Service.Config 中声明，使 cordis.yml 能自动校验。
- 启动期错误统一通过 installFailLoud + assertEntriesActivated 包装，区分 'host preparation failed' 与 'plugin tree failed to load' 两个阶段。
