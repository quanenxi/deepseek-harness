- 每个包都遵循 `src/index.ts` 为主入口、`src/invariant.ts` 为不变量断言、`package.json` 中通过 `exports` 同时暴露 `.` 与 `./invariant` 子路径的结构。
- 配置对象与其 JSON Schema 成对定义：先声明 TS interface，再用 `schemastery` 的 `z.object({...})` 构造同名 `Config` 常量用于运行时校验。
- 通过 `peerDependencies` 声明宿主能力（如 `dsh-tools`、`dsh-settings`、`dsh-agent`），并将对应类型放入 `devDependencies`，保持运行时无侵入。
- 插件行为通过 `apply(ctx, config)` 或继承自 `Service` 的构造函数完成副作用注册，而非在模块顶层执行副作用。
