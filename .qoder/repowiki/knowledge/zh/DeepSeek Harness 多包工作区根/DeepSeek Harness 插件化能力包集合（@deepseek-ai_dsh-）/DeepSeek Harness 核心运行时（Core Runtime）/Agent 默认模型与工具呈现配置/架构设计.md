本模块由两个独立的 Cordis 插件包组成：
- `agent-default-model`：导出 `AgentDefaultModelConfig` Service，通过 `@deepseek-ai/dsh-settings` 的 `installSettingsSection` 将默认模型（provider/model/reasoningEffort）持久化到 settings 文档，并以闭包 `source` 在设置变更时热更新；对外暴露 `currentSelection()` 返回解耦的 `ModelSelection`，并通过 `saveSelection()` 写回 settings。
- `agent-tool-presentation`：以 Cordis plugin 形式暴露 `name='tool-presentation'`、`inject=['tools']` 和 `apply(ctx, config)`，根据 `mode` 调用 `ctx.tools.presentAs('native'|'code'|'both')`；对 `code`/`both` 模式通过 `ctx.inject(['codeRuntime'], ...)` 延迟等待代码运行时就绪，使未装配 code runtime 的部署在 preset 激活阶段即失败。
依赖方向单向指向宿主层（`dsh-tools`、`dsh-settings`、`dsh-agent`、`dsh-llm`），不反向依赖 Agent 运行期；两个包均通过 `exports` 字段同时发布编译产物 `lib/*` 与源码映射 `src/*`，并附带独立 `invariant` 子路径。
