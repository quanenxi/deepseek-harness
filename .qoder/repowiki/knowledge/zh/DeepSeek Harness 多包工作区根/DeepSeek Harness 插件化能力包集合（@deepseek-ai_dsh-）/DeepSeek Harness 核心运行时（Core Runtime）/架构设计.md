本模块由三个协作层次组成：
- boot（app-boot + cmdline）：进程入口层，负责加载 .env 分层、解析 cordis.yml、安装 fail-loud 守卫、挂载根 Include 并驱动 Cordis Loader 直到所有 fiber 激活，同时提供 HMR 下的用户补丁热重载。
- host（apiproxy、directory-picker-*、webserver、frontend-static、plugin-inventory）：宿主能力聚合层，以 ApiProxyService 为核心，通过 `inject` 声明式消费 core 提供的 agents、sessions、tools、llm、workspaceRegistry 等服务，并以 transport-agnostic 的 ApiProxy 契约向客户端暴露 RPC；各目录选择器实现按平台探测组合。
- core（agent-loop、session、tools、system-prompt、scope、agent-default-model、agent-tool-presentation）：Agent 运行时内核，基于 ScopeKey 的范围化事件路由、基于事件溯源的 Session 存储、工具注册/执行流水线以及系统提示组装，被 host 层通过服务名注入消费。
三者通过 Cordis Context 的服务名契约解耦：boot 启动 Loader → host 作为 surface 注册 ApiProxyService → core 作为 provider 暴露 sessions/tools/agents 等服务 → client 经 apiproxy 的 fetch carrier 调用。配置与补丁通过 cordis-plugin-include 的 PatchOptions 在 boot 阶段一次性扁平化合并，保证同一份 cordis.yml 在开发 HMR 与生产打包下行为一致。
