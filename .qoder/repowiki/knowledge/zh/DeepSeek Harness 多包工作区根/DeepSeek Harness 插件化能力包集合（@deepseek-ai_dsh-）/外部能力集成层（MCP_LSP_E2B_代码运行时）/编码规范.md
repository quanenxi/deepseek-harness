- 所有包均以 `export const name` + `export const inject = [...]` + `export async function apply(ctx, config)` 形式暴露 Cordis 插件入口，或通过继承 `SubprocessRuntime`/`CodeRuntime` 的类作为 Service Definition。
- 配置对象统一使用 Schemastery (`z.object` / `z.union`) 声明，并在构造函数或 `apply` 中校验正整数、上限（引用 `MAX_TIMER_DELAY_MS`）等语义约束，失败即抛错而非静默降级。
- 每个包导出独立的 `invariant.ts` 并通过 `exports.invariant` 字段暴露，供上层消费断言而不引入主逻辑。
- 生命周期资源（连接、实例、handle、terminal）集中保存在类实例的 Set/Map 中，并通过 `ctx.effect(() => cleanup, 'xxx')` 注册副作用，确保 fiber 卸载时有序回收。
- 对外部不可信输入（worker 消息、LSP 响应、binding 名称）一律先做白名单/正则校验再使用，拒绝未知字段与原型链查找，避免注入攻击。
- 包结构统一为 `src/*.ts` 源码 + `lib/` 编译产物 + `tests/*.spec.ts` 单元测试 + `README.md`/`README.zh.md`/`README.i18n.yaml` 多语言文档。
