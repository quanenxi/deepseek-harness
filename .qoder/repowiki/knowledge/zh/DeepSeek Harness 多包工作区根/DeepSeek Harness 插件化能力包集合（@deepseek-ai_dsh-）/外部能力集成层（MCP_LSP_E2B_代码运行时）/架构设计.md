本模块由四个并列的 npm 包组成，每个包都遵循统一的 Cordis 插件/Service Definition 模式：通过 `package.json` 暴露 `lib/index.js` + `lib/invariant.js` + `lib/types/**/*.d.ts`，并以 `apply(ctx, config)` 或继承 `SubprocessRuntime`/`CodeRuntime` 的类作为入口。

- `packages/mcp/mcp-client`：实现 `@deepseek-ai/dsh-mcp-client`，通过 `connection.ts`/`transport.ts` 以 stdio 或 streamable-http 连接 MCP server，将工具注册到 `ctx.tools`，使用 WeakMap 按 `ctx.root` 隔离 `serverName` 命名空间，并通过 Schemastery 校验带 `transport` 字段的联合配置。
- `packages/lsp/{lsp,lsp-stdio,tool-lsp}`：`lsp` 定义 LSP provider 类型；`lsp-stdio` 实现 `LocalLspProvider`，按 canonical workspace 单例池化 `LspInstance`，通过 `ctx.subprocess.spawn` 启动语言服务器并翻译 JSON-RPC，支持传输失败后透明重试；`tool-lsp` 把 LSP 查询渲染为工具调用。
- `packages/e2b/{e2b,fs-e2b,subprocess-e2b}`：`e2b`/`fs-e2b` 提供 E2B sandbox 与文件系统抽象；`subprocess-e2b` 实现 `E2BSubprocessRuntime`，在共享 sandbox 内分配 `/processes`/`/terminals` 状态目录，通过 `sandbox.commands.run` 解析 PATH 并启动子进程与终端，统一维护 live handles 集合并在 teardown 时聚合清理。
- `packages/code-runtime/{code-runtime,code-runtime-worker-thread}`：`code-runtime` 定义 `CodeRuntime` 抽象与保留全局列表；`code-runtime-worker-thread` 用 Node `worker_threads` 运行每段 TypeScript 程序，通过 stripTypeScriptTypes 剥离类型、自定义 JSON 编解码器 (`worker-json.ts`) 跨边界传递值，并用 `OutputLedger` 限制日志/输出字节数，同时以 eventLoopUtilization 和 wall-clock 双重预算控制执行。

依赖方向单向向外：各实现包仅依赖 `@deepseek-ai/cordis`、`@deepseek-ai/schemastery`、`@deepseek-ai/dsh-timeout` 及对应 seam 接口（`dsh-subprocess`、`dsh-code-runtime`、`dsh-lsp`），不反向依赖宿主，从而可在本地或远程环境互换实现。
