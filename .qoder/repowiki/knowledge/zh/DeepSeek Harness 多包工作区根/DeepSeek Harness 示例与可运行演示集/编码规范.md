- 每个示例目录自包含 cordis.yml 插件清单与 package.json，通过 workspace:* 依赖根仓库的 dsh-* 插件完成运行时拼装。
- 示例配置统一使用 !!js 内联表达式读取 DSH_* 环境变量（如 DSH_SNAPSHOT、DSH_PERMISSION_MODE、DSH_CWD）以切换生产/快照行为。
- 快照测试采用 input.json + session.jsonl + stdout.expected.jsonl 三件套结构，必要时附带 replay.override.json 与 system-prompt.expected.md。
- 子代理同时注册 spawn 与 fork 两种 provider（tool-subagent-spawn-in-process / tool-subagent-fork-in-process），并以 continuable 与 one-shot 两种 backgroundMode 区分生命周期。
- 文件系统访问一律经 @deepseek-ai/dsh-fs-sandbox + @deepseek-ai/dsh-fs-observation-policy 组合，读写受 sandbox-policy 的 mode（workspace-write / danger-full-access）约束。
