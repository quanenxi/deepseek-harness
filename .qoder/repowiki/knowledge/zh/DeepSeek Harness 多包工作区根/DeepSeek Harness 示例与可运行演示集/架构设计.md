本模块是工作区顶层的示例集合，每个子目录（acp-agent、headless-agent、jsonrpc-agent、mcp-memory、web-cordis、web-schedule）都是一个独立的 Cordis 应用包，拥有自己的 cordis.yml 插件清单和 package.json，并通过 workspace:* 依赖根仓库中的 dsh-* 插件包来拼装运行时。
- acp-agent：基于 @deepseek-ai/dsh-acp-demo 的 ACP 自动化服务器，通过 JSON-RPC stdio 暴露 session/permission/cancellation，使用 sandbox-policy + fs-sandbox 实现权限隔离，并挂载 subagent/workflow/tool-fs/bash/hooks 等能力。
- headless-agent：一次性编码 Agent，预创建 main agent，输出机器可读结果，支持 compaction、checkpoint、subagent fork/spawn、Ralph、todo 等。
- jsonrpc-agent：无头 JSON-RPC 服务端，stdout 专用于协议，不启用 terminal/UI，通过环境变量注入 model/system prompt/cwd。
- web-cordis / web-schedule：作为 dsh web 的 patch overlay 覆盖默认 Web bundle，分别注入 cordis 工具与定时任务能力。
- mcp-memory：通过 MCP 客户端连接第三方记忆服务。
- tests/ 下按示例分目录组织 snapshot 与 e2e 用例，采用 input.json + session.jsonl + stdout.expected.jsonl 的快照对比模式，fixture 子目录提供可复用的 cordis 驱动与 mock LLM。
