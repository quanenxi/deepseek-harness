- 每个可执行脚本旁放置同名 `.spec.ts` 单元测试，使用 Vitest 对纯函数逻辑进行回归测试。
- Gate 定义统一通过 `pnpmScript(id, scriptName, { label, needs, env })` 或 `pnpmExec` 构造，并以 `needs` 声明依赖形成 DAG。
- 校验类脚本返回结构化错误集合（如 `PackageInvariantViolation[]`），由上层格式化输出，便于断言与报告。
- 对外暴露的 CLI 参数解析函数集中处理 flag 合法性与互斥组合，并在非法时抛出明确错误消息。
- 文件路径统一以仓库相对路径、正斜杠形式传递，跨平台分隔符在入口处归一化。
- 需要持久化的状态（如翻译配对记录、manifest）采用 JSON/YAML 侧车文件 + 严格 schema 校验的方式管理。
