- 每篇文档采用三件套命名：`<topic>.md`、`<topic>.zh.md`、`<topic>.i18n.yaml`，后者记录两端最新确认时的 git blob hash 以保证成对同步。
- 中文文件在 H1 后立即附带 `[English](xxx.md) | 中文` 语言切换器，英文文件反向附带 `English | [中文](xxx.zh.md)`，生成源除外。
- 子树内每子系统一篇参考页，标题即子系统名，正文聚焦该子系统的数据结构、语义与生成的 Cordis API 片段，不重复行为叙述。
- 教程类文档使用编号前缀（如 `01-first-plugin.md`）表达有序学习路径，参考类文档则按主题平铺并列。
- Markdown 段落保持单行（软换行），代码块使用 fenced `ts` 且必须编译通过，类型声明通过 `type-equiv` / `public-api` 标记参与漂移检测。
- 跨引用统一使用相对 Markdown 路径与 `#fragment` 锚点，禁止裸文件名或自由文本引用，由 `verify-md-links` 强制校验。
