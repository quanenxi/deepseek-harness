文档按 AGENTS.md 定义的“层级分类”组织：根级文件描述整体架构、模块图、能力边界、配置/工具/持久化目录等跨子系统主题；`subsystems/` 每个文件对应一个子系统参考页，并嵌入由 Cordis 服务/事件生成的 API 片段；`cordis-api/` 提供框架核心上下文、服务、事件、Fiber、注册表等独立参考；`cordis-tutorial/` 以编号步骤编排插件开发教程；`user/` 面向最终用户的网站内容（guide、develop、practice）；`cookbook/` 提供可验证的逐步操作手册；`postmortem/` 记录事故时间线；`i18n/` 集中定义术语、翻译规则与双语配对契约。所有文档遵循 `foo.md` + `foo.zh.md` + `foo.i18n.yaml` 三元配对结构，通过 `verify-translation-pairing`、`verify-md-links`、`verify-type-equiv`、`verify-doc-budgets` 等脚本在 CI 中强制一致性、链接完整性、类型等价与字数预算。
