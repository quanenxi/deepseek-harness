本地文档工作流：`pnpm run doc-sync` 触发完整检查；`pnpm run verify-translation-pairing [--write] <pair...>` 校验并重新记录中英配对哈希；`pnpm run verify-md-links` 校验相对路径与锚点；`pnpm run verify-type-equiv` 校验代码块中的 TypeScript 声明与源码等价；`pnpm run verify-doc-budgets` 校验各文档字数预算；`pnpm run gen-translation-brief <pair>` 与 `--apply` 用于扩展翻译流程。
