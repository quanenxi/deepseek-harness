本地构建需 Linux + `musl-tools` 提供 `musl-gcc`，运行 `pnpm run build:native`；非 Linux 主机直接失败。测试通过 `pnpm test` 或分别执行 `node ./test/entry.test.js` / `node ./test/launcher.test.js`。发布流程使用 `release:bump` → `release:commit` → CI 构建 → `release:assemble-prebuilds` → `release:verify` → `release:pack` → `release:publish` 系列脚本。
