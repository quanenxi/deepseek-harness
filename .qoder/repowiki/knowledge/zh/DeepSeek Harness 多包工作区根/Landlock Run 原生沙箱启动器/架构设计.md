模块以 `landlock-run/` 为独立 pnpm workspace，采用三包 npm 家族结构：`packages/entry` 暴露 JS API（`launcherPath`、`grantArgs`、`probe`），通过 `os/cpu` 字段解析对应平台的预编译二进制；`packages/linux-x64` 与 `packages/linux-arm64` 仅包含静态 musl 编译的 `landlock-run` 二进制及 `prebuilds.json` 矩阵声明，作为 entry 包的 `optionalDependencies` 按宿主架构安装。构建入口 `scripts/build.ts` 在 Linux 上读取各平台 `prebuilds.json`，用 `musl-gcc -static` 将 `packages/entry/src/main.c` 编译到目标 `bin/`，禁止交叉编译以保证审计面最小。发布流程由 `scripts/{assemble-prebuilds,pack-release,publish-release,verify-release,...}.mjs` 串联，CI 在每个架构 runner 上构建并验证产物。JS 层严格持有 CLI 契约（见 `docs/cli-contract.md`），不暴露环境变量覆盖，所有失败统一返回退出码 125，并通过 `--probe` 输出区分 `full/partial/unusable` 三种内核支持级别。
