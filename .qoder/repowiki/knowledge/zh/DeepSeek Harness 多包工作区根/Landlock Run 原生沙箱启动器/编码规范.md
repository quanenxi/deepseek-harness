- CLI 契约集中维护于 JS 层（`LAUNCHER_BIN`、`LAUNCHER_FAILURE_EXIT`、`probe` 输出解析），二进制只负责执行，不对外暴露 flag 拼写细节。
- 平台差异化通过 npm `os`/`cpu` 字段 + `optionalDependencies` 实现，entry 包不感知具体平台，仅通过 `createRequire.resolve` 解析对应包路径。
- 构建产物由 `prebuilds.json` 矩阵驱动，`scripts/build.ts` 中的 `TOOLS` 表显式声明 C 源码映射，新增工具必须同时登记两处。
- 二进制以 static-musl 方式编译（`-static -Os -Wall -Wextra -Werror -s`），确保对 glibc/musl 发行区均无需额外运行时。
- 安全相关行为禁用环境变量覆盖，测试注入通过函数参数（如 `launcherPath` 的 `resolvePackageJson`、`probe` 的 `launcher`）完成。
