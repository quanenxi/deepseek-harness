- 所有子模块通过 pnpm workspace 的 workspace:* 协议互相引用，禁止跨包硬编码路径。
- 构建与类型检查分离：host/client 分别通过 tsc -b 与 tsdown 产出，scripts 中以 --contracts-ready 区分契约就绪阶段的 lint/typecheck。
- 代码风格统一由根级 .oxlintrc.json 与 .oxlintrc.staged.json（pre-commit 用）管理，vendor 目录默认排除。
- 文档与站点通过 scripts 下的生成器（gen-*）与验证器（verify-*）双向约束，Markdown 片段变更需同步更新清单。
- Python SDK 发布严格以 package.json 版本号为准，CI 要求 tag 与 package.json version 一致后方可推送到 PyPI。
- 新增第三方依赖需在 allowBuilds/patchedDependencies 显式声明，否则安装失败，确保依赖生命周期受控。
