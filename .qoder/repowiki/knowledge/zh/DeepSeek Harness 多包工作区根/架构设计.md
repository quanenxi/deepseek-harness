根目录作为 pnpm workspace 的装配点，在 pnpm-workspace.yaml 中声明 vendor/*、packages/*/*、native/landlock-run、apps/*、website、examples、python/sdk-runtime 等成员，并通过 linkWorkspacePackages + overrides 将 @deepseek-ai/cosmokit、@deepseek-ai/schemastery 等上游框架指向本地 vendor 源码，使所有子模块共享同一份依赖解析。

- 入口与运行时：apps/cli 提供 `dsh` 命令，apps/web 提供 Web 前端；二者均基于 Cordis 配置层加载 profile、插件与预设启动 Agent 运行时，消费 packages 下按能力域拆分的插件包。
- 安全边界：native/landlock-run 以 C 静态二进制 + npm 平台包形式提供 Landlock 沙箱，被 harness 插件在进程级隔离执行 agent。
- Python 绑定：python_sdk 通过 JSON-RPC over stdio 调用 harness，CI 在 .gitlab-ci.yml 中按 linux-x64/linux-arm64/macos-arm64 三目标构建 Node 可执行并打包为 PyPI wheel，版本由 package.json 驱动。
- 文档与站点：docs 维护 Markdown 源，website（VitePress）将其投影为站点，scripts 中的生成脚本负责同步清单与链接校验。
- 质量门禁：lefthook.yml 在 pre-commit/pre-push 阶段运行 scripts 下的翻译配对、归档笔记、oxlint、third-party notices 生成等检查；package.json 的 check:* 系列脚本经 scripts/run-gates.ts 串联 CI 矩阵；vitest.config.ts 集中定义 unit/snapshot/web/e2e 等多套测试配置。
- 发布流程：根脚本 release:* 调用 scripts/release/* 完成 bump/pack/publish，Python 发布走 GitLab CI 的 python-v* 标签触发，JS 包通过 pnpm publish 发布到 npm。
